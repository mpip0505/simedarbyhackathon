OSM-only licence fallback

City of Elmina (pilot) · OpenStreetMap only · Example sites (simulated)

A licence fallback, not a second model: it lets a reduced screening run without Google Earth Engine, whose registration for this project is noncommercial. It ranks cells only by closeness to a mapped footpath (60%) and a mapped park (40%). It cannot see heat, tree cover, actual shade or species, its scores cannot be compared with the satellite model, and it does not replace the satellite method.
